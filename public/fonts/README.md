# Optional local fonts

The repository uses the installed Tahoma/sans-serif fallback. The original IRANSansX font files are not redistributed in this public-source package.

To enable your own licensed copy locally, place IRANSansX-Regular.woff and IRANSansX-Bold.woff here and add their @font-face declarations to app/globals.css. The files are ignored by Git. Review your font license before distributing them publicly.
